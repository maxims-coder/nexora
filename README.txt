NEXORA — сайт-портфолио

ЛОКАЛЬНЫЙ ЗАПУСК
Открой index.html в браузере.

ПУБЛИКАЦИЯ
Загрузи обновлённый index.html в корень репозитория GitHub.
GitHub Pages автоматически пересоберёт сайт.

ЗАЯВКИ В TELEGRAM
Форма открывает чат https://t.me/mozimka с подготовленным текстом заявки.
Посетитель должен сам нажать кнопку «Отправить». Статический GitHub Pages
не может безопасно отправлять сообщения напрямую без серверной части и
защищённого хранения токена Telegram-бота.

ПОРТФОЛИО
NOIR, FLOW и VANTA — демонстрационные концепты, не реальные клиентские заказы.

ЦЕНЫ
Цены являются стартовыми ориентирами. Согласовывай точный объём, сроки,
цену, правки и порядок оплаты до начала работы. Домен, хостинг, API и
лицензии могут потребовать отдельной оплаты.
